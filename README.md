# TradeIt – Firebase Marketplace App

TradeIt is an Android application that allows users to browse categories and items in a simple marketplace-style interface. The app integrates with Firebase Realtime Database to dynamically load and display content.

## Features
- Browse categories and view items within each category
- Real-time data updates using Firebase Realtime Database
- Toggle between category view and item view
- Sorted category and item lists (alphabetical and by recency)
- Interactive UI with RecyclerView and click/long-click actions

## Tech Stack
- Java
- Android SDK
- Firebase Realtime Database
- RecyclerView + Adapter pattern

## Key Functionality
- Subscribes to Firebase data changes and updates UI in real time
- Handles dynamic datasets with sorting and filtering
- Manages different UI states (categories vs items) within a single activity
- Implements efficient list rendering using RecyclerView

- Handling asynchronous data updates and UI synchronization
- Structuring Android apps with activities, adapters, and listeners
- Managing edge cases such as empty datasets and index errors
